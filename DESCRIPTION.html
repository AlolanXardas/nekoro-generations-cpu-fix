A tiny fix for Generations-Core that gives you back one CPU core.
Made mainly for my Nekoro Pokemon modpack, but it works in any pack with Generations-Core.

What it fixes

Generations-Core runs a background thread that prepares its Pokémon models. In version 1.2.8 that thread never rests: it keeps checking for new work over and over, so one CPU core stays at 100% for the whole game, even when you are standing still in an empty world.
That core is missing for chunk loading and other mods, and your CPU runs hotter than it needs to.

This mod changes only that one loop. The thread now sleeps until a model really needs preparing and then works exactly as before.
Nothing else in Generations-Core is touched and nothing changes in game.

• No config, just drop it in
• Client-side: on a server it does nothing, so it’s harmless in server packs
• If a future Generations-Core version fixes this itself, the mod simply stops applying and writes a note in the log

Requires

Generations-Core 1.2+
Minecraft 1.21.1: NeoForge or Fabric
