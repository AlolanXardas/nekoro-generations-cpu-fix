A fix for Generations-Core that gives you back one CPU core.
Client only.
Requires Generations-Core 1.2 or newer.

Report bugs and share ideas in the comments or on Discord.

Features

  • Generations-Core 1.2.8 keeps one CPU core busy for the whole game.
  • This mod lets that thread sleep until a model needs preparing.
  • Nothing else changes.
  • No config.
  • On a server it does nothing.
  • If Generations-Core fixes this itself, the mod stops applying.
