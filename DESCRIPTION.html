A tiny fix for Generations-Core that gives you back one CPU core.
Made for my Nekoro Pokemon modpack, but it works in any pack with Generations-Core.

Client only. Requires Generations-Core 1.2+.

What it fixes

Generations-Core runs a background thread that prepares its Pokémon models. In version 1.2.8 that thread never rests, so one CPU core stays at 100% for the whole game, even in an empty world. That core is missing for chunk loading and other mods, and your CPU runs hotter than it needs to.

This mod changes only that one loop: the thread now sleeps until a model really needs preparing. Nothing else changes in game.

  • No config, just drop it in.
  • On a server it does nothing, so it's harmless in server packs.
  • If a future Generations-Core version fixes this itself, the mod stops applying and writes a note in the log.
